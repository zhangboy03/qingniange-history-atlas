# 清年阁高中历史双图
供高中历史复习使用。在豆包工作选择本地电脑，发送这句即可开始：

> 从这个仓库下载并安装清年阁高中历史双图技能，再照里面的 ChartOrigin 样图，给我画一张十一条历史主线海报。

[下载安装包](https://github.com/zhangboy03/qingniange-history-atlas/releases/latest/download/history-study-atlas.zip) · [查看制作说明](./SKILL.md)

安装包的根目录是 `SKILL.md`。在豆包工作技能列表中，其名称为 `history-study-atlas`。若通过客户端导入，使用上面的安装包。

第一张海报沿十一条主题线追踪不同时期的变化。第二张年表分近代史、现代史和世界史，可以查同年中外史事。接着告诉豆包你容易混淆的地方，或请它逐件添加考点与易错点。
